# Qiskit-Fall-Fest-2026

## Overview

This repository contains four quantum computing challenges completed during **Qiskit Fall Fest 2026**, organized at Vishnu Institute of Technology.

The challenges demonstrate fundamental quantum computing concepts using Python, IBM Qiskit, and Jupyter notebooks.

## Challenges

### Challenge 1 — Predict the Output
- Implemented single-qubit circuits using X and Hadamard gates.
- Predicted and compared measurement outcomes.
- Executed each circuit for 100 shots.

### Challenge 2 — Make the Quantum Coin Biased
- Designed single-qubit circuits with unequal measurement probabilities.
- Used rotation gates to control measurement bias.
- Compared theoretical probabilities with experimental results.

### Challenge 3 — Can You Change the Correlation?
- Created a two-qubit Bell-state circuit.
- Added an X gate to change the measurement relationship.
- Demonstrated positive and negative correlations.

### Challenge 4 — Quantum Correlation Switch
- Designed circuits producing correlated and opposite outcomes.
- Demonstrated a correlation switch using a single X gate.
- Compared experimental results using histograms.

## Technologies Used

## Running the Notebooks

1. Install Python and the required Qiskit packages.
2. Open the notebooks using JupyterLab or Jupyter Notebook.
3. Run the cells sequentially.
4. Examine the measurement results and histograms.
